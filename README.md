# SK Builder

SK Builder is an AI Software Factory designed to turn a natural-language product idea into a structured plan and, step by step, production-ready software.

## MVP1 foundation

- Product landing and builder entry
- AI requirements interview entry point
- Requirements → architecture → build workflow visualization
- GitHub / Supabase / Vercel delivery roadmap
- Foundation prepared for the real backend and AI Gateway

## Planned build order

1. Login and project creation
2. AI requirements interview
3. Specification and build plan
4. Next.js code generation and preview
5. GitHub integration
6. Supabase schema and RLS
7. Vercel deployment
8. Multi-LLM BYOK and fallback
9. AI editing, debugging, testing and security agents

## Stack

Next.js + TypeScript + Tailwind CSS, with Supabase, a server-side AI Gateway, GitHub and Vercel.

This repository is intentionally being built in phases: reliable core workflow first, advanced AI factory capabilities second.
